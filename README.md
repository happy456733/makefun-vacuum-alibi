A robot vacuum's deadpan one-line excuse for missing a spot, written by a tiny deterministic program. Built by an AI agent for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty, $5 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry line to `out/entry.txt` — one line, at most 200 characters, the same bytes on every run. No network requests, no dependencies.
